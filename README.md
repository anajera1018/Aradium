# Aradium - Music Player for Android

## Team Members
- Anthony I. Najera

## Description
A simple offline music player for Android built with Kotlin and Jetpack Compose.

## Problem It Solves
Why this app is useful: playing local audio files in one clean app without
accounts, ads, or internet.

## Main Features
- Upload any audio file from the device
- Edit song details and cover art
- Play, pause, skip, shuffle, repeat
- Background playback with notification controls
- Create and sort playlists
- Search the library

## Technologies Used
Kotlin, Jetpack Compose, Navigation Compose, Room, DataStore, Media3 ExoPlayer, Coil

## Installation / Run Instructions
1. Clone: `git clone https://github.com/anajera1018/Aradium.git`
2. Open in Android Studio or IntelliJ IDEA
3. Let Gradle sync
4. Run on an emulator or device (API 26+)
